latest-geo v0.11.0: perf refactor, full-signal recommender, structured graded geo

Ranking (server):
- Resolve geo + learned-interest matches to bounded id sets OUTSIDE the feed
  query (5-min per-user cache) and inline them as a VALUES join — the hot
  query no longer does any per-row string matching
- Rank horizon (rr_geo_rank_horizon_days, 60d): the long tail short-circuits
  to score 0 and falls back to bumped order
- Pagination served from a per-(user, seed-bucket) cached id window
  (rr_geo_cache_topics, 150); bucket expiry is the invalidation
- Learned-interest boosts proportional to client model confidence
  ("name|weight" wire format; old plain-name profiles still parse)
- Structured location ("City, Province/State, Country" — required on save)
  with GRADED proximity: own city 1.0 > curated nearby cities 0.7 >
  province/state 0.45 > country 0.2 — towns with no posts of their own still
  get a locally-relevant feed
- GET /rr-geo/prior.json: anon-safe cold-start prior (top tags for an area)
- Optional daily city auto-tag job (rr_geo_auto_tag_cities, default OFF)

Recommender (client, v0.6):
- Impressions IntersectionObserver-gated (>=50% visible >=1s, capped per
  page/session) — below-the-fold rows no longer poison the model
- Opens dwell-graded: bounce <10s = negative, deep read >45s = strong positive
- Learns from core likes, bookmarks, $RENO tips, reply submits
- New features: author:, geo:local, rec:today/week, media:img
- Weighted profile sync, deduped by content hash, min 60s apart
- Client-side re-rank of topic-list DATA via registerModelTransformer
  (bounded lift, small-list + cold-model guards; never touches the DOM)
- Anon personalization: logged-out visitors learn + re-rank locally, no sync
- Cold-start: fresh models seed once from /rr-geo/prior.json

Location UX:
- Editor + ipinfo bootstrap produce three-part locations; save validates
  client- and server-side with a friendly error; suggestions include country
- Legacy two-part locations keep ranking (no country level) and upgrade on
  next edit

New settings: rr_geo_rank_horizon_days, rr_geo_cache_enabled,
rr_geo_cache_topics, rr_geo_match_limit, rr_geo_client_rerank,
rr_geo_anon_personalization, rr_geo_auto_tag_cities
